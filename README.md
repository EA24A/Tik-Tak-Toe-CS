## 🎮 Overview
A desktop implementation of the classic Tic-Tac-Toe game featuring an interactive graphical user interface (GUI), customizable player names, and real-time win condition evaluation.

---

## ✨ Features
- **Interactive 3x3 Grid:** Responsive button grid with turn-based color highlights (Player 1 in Blue, Player 2 in Red).
- **Win & Draw Logic:** Automatically detects winning lines across horizontal rows, vertical columns, and diagonals, as well as stalemates (draws).
- **Player Customization:** Support for entering custom player names before and during the match.
- **Game Management:** Integrated MenuStrip with quick options to reset the board or exit the application.
- **Victory Screen:** Visual highlight screen celebrating the winner upon match completion.
